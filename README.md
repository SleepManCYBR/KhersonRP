## 🌨️ О проекте

**Kherson RP** — это современный веб-проект, созданный
с акцентом на стиль, удобство и атмосферу.

Сайт выполнен в зимней тематике с использованием
тёмных оттенков, холодных голубых акцентов
и современного визуального оформления.

Наша цель — создать красивую и удобную платформу
для сообщества Kherson RP.

## 🛡️ Безопасность

В инфраструктуре Kherson RP используется **Cloudflare**.

Cloudflare помогает:

- Защищать сайт от DDoS-атак
- Фильтровать вредоносный трафик
- Ускорять загрузку страниц благодаря CDN
- Повышать стабильность и доступность сайта
